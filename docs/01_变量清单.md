# 变量清单（基于 V3.1 盘点）

整理日期：2026-10-29
范围：V3.1 七份规则文件（[`source-v3.1/`](source-v3.1/)），加上基础方案中新增的变量。

## 怎么读这份清单

**类型**：

| 类型 | 含义 |
|---|---|
| 封闭枚举 | 只能从列举项里选，例如 T01～T15 |
| 开放示例 | 列举项只是示例，可以写别的，例如主色 |
| 区间 | 数值范围，例如页数 3～10 |
| 单一默认 | 只给了一个默认值，没有可选列表，例如画幅 3:4 |
| 自由文本 | 用户自己填写，没有列举项 |

**层级**：「用户变量」指用户或账号可以设置的项；「流程变量」指 Skill 运行时自己判断和记录的项；「规则清单」不是变量，而是固定的判定条件，单独放在第七节。

## 九、盘点中发现的缺口（供补充时参考）

> 第一轮核查与扩充见 [02_变量核查与扩充.md](02_变量核查与扩充.md)。

| 变量 | 现状 | 问题 |
|---|---|---|
| 画幅（26） | 只有 3:4 一个值 | ✅ 已确认：两个平台都用 3:4 |
| 排版底（27） | 只有「浅色」 | V02、V10 等风格是否允许深色底没有说明 |
| 主色体系（25） | 5 个颜色名 | ✅ 已确认：只写颜色名，渲染时推导 HEX 并锁定 |
| 字体（28） | 只有层级，没有字体 | svg 模式需要具体字体和授权（如思源黑体、思源宋体、霞鹜文楷等开源字体） |
| 口吻（39） | 5 个词 | 每种口吻没有定义和示例 |
| 主题领域（7） | 8 大类 | 缺健康运动、美食、育儿家庭、理财、宠物等常见类目；其中部分属于需要合规约束的敏感品类 |
| 素材类型（13） | 5 类 | 没有单列「引用作品」和「数据」，但 02 七、04 B 都在用 |
| 任务范围（2） | 00 写 5 项，README 写 6 项 | 「继续剩余页」应并入 00 的定义 |
| 标题长度（34） | 20 字 | 没有和平台上限分层；封面大字和发布标题没有分开定义 |
| 话题标签 | 只说「不计字数」 | 没有数量、生成规则，不是变量 |
| 页数（15） | 3～10 | 平台的图片数上限没有写进来 |
| 质检 F 组 | 10 项里一半是账号 IP | 迁移时要改成角色资产的检查项 |
