# 小红书多主题图文｜视觉规范 V3.1

本文件定义视觉 V、版式 L、风格继承与人物配置。内容模板 T 见 01。

## 一、统一基础规范

- 画幅、排版底、主风格与配色读取 05 的本次有效配置；本文件负责具体表现方法。手机端优先阅读。
- 在已选主色体系下，中性色和必要功能色作为辅助，不无故逐页另换配色方案。
- 照片、截图和作品保留必要自然色，不为统一主色扭曲证据、物品颜色或界面信息。
- 统一字体层级、线条、边框、图标语言、图片处理与页码；布局可以变化。
- 页码显示、位置与格式依有效配置，编号细则见 06；显示时与背景有足够对比。
- 装饰服务于内容，给重要文字和画面留出空间。
- 每页有清晰焦点。需要高亮时约 1～3 处，只强调关键词、数字或短结论，不整段涂色。

使用浅色配置时，“浅色”指排版底与主要阅读区；照片局部深色不构成换风格。手写风要保证中文清晰；正文不为了氛围牺牲辨识度。

## 二、10 类视觉方向

V01～V10 均可选。原“首轮常用／探索候选”只表示验证成熟度，不是选择顺序或权限限制；按目标和素材适配度选择，不按编号设置默认。各风格的“适合”和“常用版式”是示例，不是排他分类或版式白名单。

### V01｜彩铅手绘 Sketchnote

对应原视觉 A。
适合：教程、工作流、方法、入门和案例。
特征：浅色素描纸、彩铅、半透明色块、便签、手绘卡片与箭头。
常用版式：L05、L06、L08、L09。
控制：保持学习笔记感；图标简单，手写正文清楚；避免每页堆满便签和装饰。

### V02｜商业情报手稿

对应原视觉 B。
适合：趋势、行业、公司、市场、政策和有证据的观点。
特征：编辑页、研究简报、关键数字、主结构图、细线与少量分析批注。
常用版式：L02、L03、L06、L07。
控制：按需加入 Evidence Strip 证据条，标注关键来源、时间和事实状态；事实、推演、待观察容易区分；避免传统企业 PPT 和深色科技大屏。

### V03｜极简信息卡

适合：职场、学习、清单、科普、方法和观点。
特征：清晰中文排版、充足留白、规则分区、少量色块和简洁图形。
常用版式：L01、L03、L08、L09。
控制：靠层级组织信息，不把所有内容拆成同样大小的小卡片；避免变成应用仪表盘。

### V04｜生活方式杂志

适合：穿搭、家居、旅行、兴趣、生活观察与人物故事。
特征：大图、编辑式标题、短图注、网格对齐和少量栏目标签。
常用版式：L01、L04、L10、L13。
控制：图片与文字共同表达一个观点，中文字号适合手机；不照搬印刷杂志的密集小字或跨页大图。

### V05｜手账拼贴

适合：成长记录、读书、计划、生活管理和复盘。
特征：纸张、便签、照片、票据、胶带、手写标注与轻微错落。
常用版式：L06、L09、L10、L14。
控制：阅读顺序明确，装饰数量克制；同页素材拼贴围绕一个观点，不能混入其他完整页面。

### V06｜实拍／截图批注

适合：实际操作、收纳改造、工具演示、物品观察和测评。
特征：真实图片或截图、箭头、圈注、局部放大、简短说明。
常用版式：L04、L05、L10、L11。
控制：使用真实素材支撑真实界面、结果和体验；保留截图中必要文字，遮去无关个人信息；模拟图需明确为示意。
素材不足时说明缺口。策划确认前可推荐说明图；确认后按 05 的变更边界处理，不静默将实拍改成模拟。不生成虚假证据。

### V07｜扁平插画科普

适合：概念、机制、生活知识、沟通与学习。
特征：简化形状、有限色板、清晰人物与物件关系、场景示意。
常用版式：L03、L05、L07、L11。
控制：插画解释关系，保持对象比例与语义合理；机制图中的方向、位置与标签需准确。

### V08｜情境漫画／对话

适合：沟通话术、职场情境、生活共鸣与故事。
特征：统一角色、少量分格、动作、短对话和清楚的阅读顺序。
常用版式：L12，也可搭配 L03。
控制：同页可参考 2～4 格组织一个情境，这是密度建议而非硬限制；每格不是一张独立海报。对话不挤满气泡；剧情人物不自动视为账号 IP；示例不伪装为真实聊天。

### V09｜图鉴／档案页

适合：分类辨识、消费选择、物品、风格与兴趣入门。
特征：对象展示、编号、标签、统一观察维度和简短说明。
常用版式：L03、L07、L09、L11。
控制：同类对象采用可比展示条件；编号表示条目，不作为多个正式页码；避免一页塞入过多对象。

### V10｜书页／阅读批注

适合：读书、文化、审美、观点和深度思考。
特征：书籍感排版、短引文、页边批注、关键词与克制分隔线。
常用版式：L01、L03、L10。
控制：正文清晰，批注少而具体；引用与自己的分析分开，不伪造书页和作者原话。

### 风格重合与素材组合

主风格决定整套的字排、线条、配色和图片处理。照片、截图、引文、局部对话与图表可以进入其他主风格，使用它们不自动构成第二主风格。例如 V04 可以有实拍批注，V03 可以有漫画示例，但不能各页随意切换完全不同的视觉语言。

| 容易重合的方向 | 区分依据 |
|---|---|
| V01 与 V05 | 学习推导与流程笔记选 V01；记录、素材拼贴与日记感选 V05 |
| V02 与 V04 | 证据、数字与判断层级为主选 V02；图片与生活观察的编辑叙事为主选 V04 |
| V03 与 V09 | 通用信息层级为主选 V03；对象及统一观察字段为主选 V09 |
| V04 与 V06 | 大图编辑叙事为主选 V04；保真的操作、细节和结果批注为主选 V06 |
| V07 与 V08 | 图形解释概念为主选 V07；人物行动与对话推进为主选 V08 |

## 三、14 种单页版式

| 编号 | 版式 | 表达目标与控制 |
|---|---|---|
| L01 | 大标题＋核心视觉 | 封面、主张或结果；一个最大焦点，必要时以字排为主 |
| L02 | 大数字＋解释 | 聚焦一个关键数字；交代单位、口径、时间和必要来源 |
| L03 | 左右对照 | 让两种选择或做法可比；维度对齐，手机上避免过窄列 |
| L04 | 前后对比 | 展示变化；说明条件、时间与差异，不伪造效果 |
| L05 | 步骤流程 | 展示先后与输入输出；节点文字短，箭头方向明确 |
| L06 | 时间线／日程 | 表达经历、阶段和安排；时间顺序准确 |
| L07 | 二维矩阵 | 按两个维度分类；坐标轴、象限和放置依据明确 |
| L08 | 决策树 | 根据条件选择路径；分支少且互不含糊 |
| L09 | 分组清单 | 展示准备项、资源或建议；有分组依据与优先级 |
| L10 | 图片／截图＋批注 | 解释操作或细节；文字不遮住关键证据 |
| L11 | 对象图鉴＋标签 | 展示对象与特征；统一观察维度与标签位置 |
| L12 | 对话／漫画分格 | 展现场景与回应；所有格共同服务一个页面观点 |
| L13 | 地图／路线 | 展示空间与行进顺序；真实路线须核实，示意图注明 |
| L14 | 工作纸／打勾表 | 用于记录、自查、安排；字段有意义，留出可用空间 |

一个主版式可以容纳必要的辅助元素。表格、多个卡片或漫画分格只要仍是一个完整页面，就不属于多页拼版。详见 06。

图表选择先看表达目标，再看形式。排名、时间变化、占比、空间关系不使用同一种图表硬套；没有数据依据时不画看似精确的统计图。

## 四、配色与字体

- 根据主题、账号与风格选择一个主色体系，不根据创作者性别自动选色。
- 可用鼠尾草绿、灰蓝、暖棕、酒红、低饱和紫等；它们是示例，不是固定分类。
- 标题、正文、注释建立少而明确的字号层级。
- 正文使用清晰中文；手写体、衬线感或装饰字主要用于标题与少量批注。
- 高亮沿用主色或克制的辅助色；功能状态同时使用文字或符号，避免只靠颜色识别。

## 五、Style Anchor 与风格参数

按 05 的授权状态生成或复用 P1。采用后记录以下参数；用户免确认时记录授权采用，不冒称经用户看图确认。已有风格的局部修改无需重新生成 P1。

| 参数 | 需记录的内容 |
|---|---|
| 风格 | V 编号及核心视觉词 |
| 色彩 | 主色、辅助色、中性色的角色 |
| 背景 | 排版底色、材质、纹理程度 |
| 字体 | 标题、正文、标签、批注的字体感与层级 |
| 图形 | 线条、箭头、边框、卡片与图标语言 |
| 图片 | 照片／截图的裁切、圆角、边框、色彩处理 |
| 强调 | 高亮、圈注、数字和信息焦点的表达方式 |
| 密度 | 留白、文字量、对象数量与安全边距 |
| 页码 | 依有效配置的显示、位置、格式、字色与字号感 |
| 人物 | 是否启用账号 IP、参考图与动作边界 |

P1 不包含的正文、表格和图片处理，由这些参数补充，首张内页进行适配检查。保持风格统一，不复制封面构图到每一页。

## 六、人物与角色

人物模式：不使用账号 IP／沿用现有 IP／使用创作者提供的指定 IP。

- 是否启用账号 IP、封面是否出现，读取 05 的有效配置；仅上传参考图不等于启用。
- 现有角色图是可选参考，不自动代表每位使用者。
- 需要新账号角色时，使用明确的角色参考；不根据使用者性别自动更换角色。
- 出现页与频率由叙事需要决定，不设固定露出配额。
- 账号 IP 出现时继承发型、服装、比例与识别特征，只辅助操作、观察或批注。
- 剧情人物可用于漫画和演示；同一故事保持身份与外观连续。

## 七、素材与参考

真实照片、界面、测评结果和引用作品由可核实素材支持。生成插画可以表达概念或场景，但不得冒充真实操作截图、使用记录或原作品。

保真边界：允许为排版裁切、缩放、遮去无关个人信息、添加边框与批注；不能改变关键文字、数值、按钮状态、物品特征或前后效果。生成式重绘不是保真证明；出现证据内容变化时，应恢复原素材后重新排版与核查。替换注释层不能变成重写事实。
