# 小红书多主题图文｜内容结构规范 V3.1

本文件定义主题分类、T01～T15 内容模板与页面角色。视觉 V 和单页版式 L 见 02。

## 一、主题、需求与模板分别判断

主题回答“讲什么”，模板回答“怎么讲”。先写清读者需求，再选一个主模板；必要时借用一个辅助模板，不把多个完整模板叠加成长篇。

| 主题范围 | 可展开方向 |
|---|---|
| 职场事业 | 表达协作、求职转岗、职业技能、项目经验 |
| 学习成长 | 学习方法、阅读、习惯、阶段复盘 |
| AI 与数字生活 | 工具、操作、资料管理、工作流、产品变化 |
| 生活管理 | 家居、收纳、搬家、时间安排、日常准备 |
| 消费决策 | 需求分析、预算、物品选择、实际测评 |
| 兴趣审美 | 穿搭、摄影、艺术、设计、手作、文化 |
| 城市出行 | 路线、周末安排、旅行准备、空间体验 |
| 沟通关系 | 表达需求、边界、反馈、具体生活情境 |

主题清单可以继续扩展，不与性别、模板或画风绑定；具体读者由账号定位决定。

| T07 | 避坑／纠错 | 哪种做法有问题，怎样修正 |
| T08 | 体验／测评 | 在明确条件下，实际表现如何 |

### 模板重合时如何选

按读者最主要的收获确定主模板，不按话题或页面外形选。以下重合正常存在，辅助模板可提供局部结构，但只用主模板决定正文的体裁默认。

| 容易重合的模板 | 主选依据 |
|---|---|
| T01 与 T12 | 完成一次任务用 T01；跨阶段行动、记录与调整用 T12 |
| T01 与 T14 | 重在照着完成操作用 T01；重在理解概念和机制用 T14 |
| T02 与 T06 | 用案例提炼做法用 T02；按标准整理可用条目用 T06 |
| T04 与 T08 | 帮读者按条件选择用 T04；回答真实测试表现用 T08 |
| T07 与 T14 | 定位并修正具体错误用 T07；建立基础理解用 T14 |
| T09 与 T10 | 事件过程、选择与结果是主线用 T09；处境与新视角是主线用 T10 |
| T10 与 T11 | 主要让人理解处境用 T10；主要提供具体表达方式用 T11 |
| T05 与 T12 | 识别当前状态用 T05；实施并复盘行动计划用 T12 |
| T06 与 T13 | 资源与物品集合用 T06；有时空和预算约束的安排用 T13 |
| T14 与 T15 | 理解一般概念或原理用 T14；分析具体作品的构成与效果用 T15 |

同一选题并非只能归一类。例：通勤包实测可选 T08，按需求选包可选 T04；两者借用同一组观察维度，不必重复做两篇结构。

## 三、15 类模板

以下箭头表示叙事环节，不表示一环必须占一页。页数按 05 解析的本次有效配置决定；不照抄环节数，不拆低价值页面。用户明确单页或其他页数时不强制扩成默认套图。

### T01｜教程／工作流

适合：工具操作、从零开始、技能入门、流程搭建。
结构：要完成的任务 → 适用条件／准备 → 核心步骤 → 实际示例 → 易错点 → 完整流程与第一步。
必须：输入、动作、输出清楚；必要时展示可检查的结果。
避免：只列功能，缺少完成任务的路径。

### T02｜案例／方法

适合：案例拆解、多种做法、经验方法。
结构：问题 → 判断标准 → 案例／方法 → 横向归纳 → 如何开始。
必须：每个案例说明场景、做法和可借鉴条件；数量服务于判断。
避免：案例来源不明，或每个方法只是名称不同。

### T03｜趋势／资讯／行业判断

适合：产品变化、模型发布、公司动作、市场、政策与行业观察。
结构：关键变化 → 为什么关注 → 已确认事实 → 背景与影响 → 分析判断 → 行动建议与待观察变量。
必须：事实、判断和待观察分开；数据、时间和功能状态有来源。
避免：把媒体猜测、宣传话术或推演写成确定事实。

### T04｜对比／选型

适合：工具、物品、服务、方案和路线选择。
结构：先明确需求 → 比较标准 → 核心差异 → 场景匹配 → 不适合的条件 → 选择建议。
必须：比较对象与条件可比；把差异翻译成对读者的实际影响。
避免：只列参数，或无依据地宣布“最好”。

### T05｜层级／自测／互动

适合：技能阶段、自查、状态识别和轻互动。
结构：自查问题 → 判断坐标 → 不同表现 → 如何改进 → 下一步行动／讨论。
必须：用可观察行为区分类型；自编模型标注为本篇整理框架。
避免：人格贴标签，或把趣味自测包装成诊断。

### T06｜清单／资源整理

适合：物品准备、资源目录、工具包、收藏清单。
结构：使用场景 → 筛选标准 → 分组条目 → 适用条件与使用顺序 → 优先从哪项开始。
必须：每个条目说明为什么入选、何时使用；涉及链接、价格和可用性时核实。
避免：无标准堆数量、复制营销清单。

### T07｜避坑／纠错

适合：常见误区、失败排查、错误示范与改进。
结构：具体做法 → 可能的问题 → 原因与条件 → 修正动作 → 对照示例 → 自查要点。
必须：说明错误成立的条件，给出可执行修正。
避免：把个人偏好说成普遍禁忌。

### T08｜体验／测评

适合：工具、生活用品、服务与实际使用观察。
结构：想验证的问题 → 样品／版本／测试条件 → 观察记录 → 优点与限制 → 适合谁 → 结论。
必须：说明测试主体、观察时间、条件和局限。使用者亲测需其提供依据；助手实际执行的可验证测试应说明测试主体；公开测试可引用并标注原测试者，不能改称使用者亲测。未实测时，在策划阶段推荐资料对比或测评方案；已经确认的实测任务不能静默换成另一种内容。
避免：虚构使用经历、数据或前后效果。

### T09｜经历／故事复盘

适合：转岗、学习、项目、生活变化与阶段总结。
结构：起点 → 关键选择 → 行动与转折 → 结果 → 反思 → 可借鉴条件。
必须：真实经历有素材；虚构或复合案例明确标注；个人结果说明条件。
避免：给使用者编造第一人称经历，把个案包装成必然路径。

### T10｜共鸣／观点

适合：工作与生活处境、成长观察、关系边界。
结构：具体处境 → 感受与问题 → 原因或另一种解释 → 新视角 → 一个小行动／开放结尾。
必须：有场景、有理由，容纳不同处境；可用字排、短对话和场景图表达。
避免：空泛金句、制造性别对立、替读者下心理诊断。

### T11｜沟通／话术

适合：提出需求、拒绝、反馈、协商和澄清。
结构：人物与场景 → 沟通目标 → 常见表达与改写 → 表达逻辑 → 使用边界与替代说法。
必须：说明角色关系和权力差异；话术作为可调整示例。
避免：承诺一句话解决复杂关系，或伪造真实聊天截图。

### T12｜挑战／习惯养成

适合：阅读、练习、整理、学习和长期行动。
结构：目标与起点 → 最小行动 → 阶段计划 → 记录工具 → 遇阻调整 → 阶段复盘。
必须：目标可观察、行动可持续，允许调整；计划与已完成的记录明确区分。
避免：把预设计划写成已实现成果。

### T13｜攻略／安排

适合：出行、路线、活动、准备事项和日程安排。
结构：人群与约束 → 推荐安排 → 时间／预算／空间顺序 → 关键提醒 → 备选方案 → 出发或执行清单。
必须：涉及营业、交通、预约、收费等会变化的信息时核实，并注明适用日期。
避免：无视预算、移动时间、体力与个人限制。

### T14｜概念／原理科普

适合：生活知识、AI 概念、文化常识、兴趣入门。
结构：一个问题 → 基本概念 → 机制／分类 → 生活例子 → 常见误解 → 如何应用或继续了解。
必须：区分定义、类比与例外；图鉴、分类表和 FAQ 可作为子结构。
避免：用类比替代事实，或将简化模型说成完整原理。

### T15｜审美／作品拆解

适合：穿搭、家居、摄影、设计、艺术和作品分析。
结构：目标效果 → 关键元素 → 组合关系 → 对照分析 → 可借鉴动作 → 适用场景。
必须：区分可观察特征与个人偏好，明确引用作品与素材来源。
避免：只说“高级”“有氛围”，不给具体观察和操作。

## 四、页面角色按模板安排

- 封面：主题和阅读价值优先，可用结果、问题、场景或核心主张。
- 起始内页：可先给结论、冲突、条件、标准、路线或概念，不强制解释“为什么”。
- 中间页：承担真正的信息推进，避免相邻页换词重复。
- 收束页：根据体裁选择总结、选型表、行动、复盘、清单或余味；无需每篇都画完整流程。
- 3 页内容可合并背景与标准、结果与行动，不能丢失理解所需条件。

## 五、每页最低结构

每页最低结构与页码显示按 05 的本次有效配置执行；具体编号、局部交付与页数变更见 06。本节不另设不可覆盖的格式要求。

主要表达结构可为图示、照片批注、对话、漫画、字排、表格或工作纸。高亮只强调必要关键词；焦点已由标题或画面表达时，无需再加重复结论卡片。
