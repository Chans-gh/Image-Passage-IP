# 小红书多主题图文｜执行与质检清单 V3.1

按阶段与本次范围检查，不适用项标为“不适用”，不当作失败。此清单不新增规则、默认值或审批节点；先按 05 解析有效配置，定义冲突按 05 的归属表处理，步骤按 00 执行。

## A｜选题与读者

- [ ] 创作者身份、目标读者、主题分别明确。
- [ ] 具体场景、主要问题、整篇核心观点明确。
- [ ] 内容能提供方法、判断、筛选、观察、情境理解或可借鉴经验。
- [ ] 没有按性别预设主题、审美、能力或称呼。
- [ ] 所需工具、预算、时间和知识前提符合目标读者。

## B｜事实与真实素材

- [ ] 需要核实的当前信息已查证，关键来源和日期可追溯。
- [ ] 产品名、人物身份、时间、功能状态、价格、数字和单位准确。
- [ ] 重大事实优先原始来源，不用单一二手截图支撑重大结论。
- [ ] 已确认事实、个人经验、分析建议、待观察和演示示例按需区分。
- [ ] 第一人称经历、亲测、前后结果有使用者提供的依据。
- [ ] 演示／虚构示例明确标注，没有冒充真实记录。
- [ ] 专业结论使用适当专业来源，适用条件与已知边界清楚。
- [ ] 引用、作品、截图和真实人物信息有必要来源，去除无关个人信息。

## C｜模板与整篇结构

- [ ] 主模板 T01～T15 选择有理由，辅助模板没有造成重复。
- [ ] 总页数符合本次有效配置；单页、局部任务和用户指定的非默认页数未被误拒。
- [ ] 没有凑页、为了固定页序增加空泛内容。
- [ ] P1 让目标读者知道主题与阅读价值。
- [ ] 起始内页、转折和结尾符合所选体裁，不机械套固定角色。
- [ ] 每页一个核心观点，相邻页面有推进。
- [ ] 末页完成该体裁需要的收束，不强制每篇都放完整流程。

按主模板追加检查：

| 模板 | 必查项 |
|---|---|
| T01 | 输入、动作、输出和结果检查明确 |
| T02 | 案例有依据，可借鉴条件明确 |
| T03 | 事实、推演和待观察分开 |
| T04 | 对象与条件可比，有场景化选择 |
| T05 | 依据可观察行为，不把自编自测当诊断 |
| T06 | 有筛选与分组标准，条目可用 |
| T07 | 错误成立条件与修正动作具体 |
| T08 | 测试条件、观察记录、局限与适合谁明确 |
| T09 | 经历依据、事件顺序、选择和反思完整 |
| T10 | 有具体处境与理由，避免空泛标签 |
| T11 | 场景、关系、沟通目标和替代表达明确 |
| T12 | 计划与完成记录分开，允许调整 |
| T13 | 约束、安排、时间成本与备选明确 |
| T14 | 定义、类比、机制与例外准确 |
| T15 | 观察与偏好分开，有可借鉴动作 |

## D｜页面文案

- [ ] 每页标题、主要表达结构与短文案符合有效配置，页面与素材内部的标题层级清楚。
- [ ] 信息焦点清楚，可是关键句、数字、动作、结果或转折。
- [ ] 没有为了凑强调句重复标题和正文。
- [ ] 手机正常阅读时标题、正文、注释能辨识，没有密集小字。
- [ ] 产品名、数字、单位、引文、英文拼写统一。
- [ ] 无错字、乱码、截断、遮挡和不明缩写。
- [ ] 页码显示与位置符合有效配置，正式编号依 06；素材内的页码、编号未被误判。

## E｜风格与单页版式

- [ ] 主风格、配色、排版底和画幅符合有效配置；没有把项目默认重复施加为硬限制。
- [ ] 每页主版式 L01～L14 对应表达目标。
- [ ] 字体层级、边框、箭头、图标和图片处理统一。
- [ ] 留白与文字密度适合手机，装饰没有挤压信息。
- [ ] 高亮仅标必要重点，功能状态不只靠颜色。
- [ ] 照片和作品的必要自然色未被错误改变。
- [ ] 图表有合适的表达目的、口径、标签与来源；无无依据精确数据。

按风格追加检查：

| 风格 | 必查项 |
|---|---|
| V01 | 纸感、彩铅与手绘一致，正文清晰 |
| V02 | 研究与证据层级清楚，证据条按需使用 |
| V03 | 字排层级清楚，卡片没有碎片化 |
| V04 | 大图与短文案协同，无印刷杂志式密集小字 |
| V05 | 拼贴阅读顺序清楚，装饰不过量 |
| V06 | 实拍／截图真实，批注不遮关键证据 |
| V07 | 对象、机制、方向与标签正确 |
| V08 | 分格共同服务一个观点，人物与对话连续 |
| V09 | 对象与观察维度可比，编号不冒充页码 |
| V10 | 引文与分析分开，书页感不影响可读性 |

## F｜人物与 Style Anchor

- [ ] 已明确不使用账号 IP、沿用现有 IP 或指定 IP。
- [ ] P1 的账号 IP 安排符合有效配置，剧情人物未与账号 IP 混淆。
- [ ] 没有因使用者身份自动套用或替换角色。
- [ ] 账号 IP 出现时与所选参考图一致，承担叙事作用。
- [ ] 人物次数按需决定，没有固定露出配额。
- [ ] 剧情人物与账号 IP 区分，跨页身份和外观连续。
- [ ] 已按 05 的当前状态与授权进入相应阶段；免确认授权没有被误记为用户看图确认；已有节点未重复确认。
- [ ] 已记录风格参数，后续页面继承 P1 与参数。
- [ ] 首张内页的正文、表格、图片适配已检查。
- [ ] 风格一致，页面布局可随内容变化。

## G｜每次生成前

- [ ] 当前只处理一个正式页码和一个页面主任务。
- [ ] 当前页的实际文字、结构、素材与策划一致。
- [ ] 引用的是本次已采用的 P1 和适用角色参考，采用状态符合授权记录。
- [ ] 提示中没有要求把其他完整页面画入当前画布。
- [ ] 生成目标是符合有效画幅的独立正式页面。
- [ ] 内部卡片、照片组合或漫画分格只服务当前页观点。

## H｜每张生成后

- [ ] 只有一个完整页面，页面标题与正式页码符合配置，截图内原有标题与页码按素材处理。
- [ ] 实际画幅符合有效配置，没有用多页缩略图、海报墙或拼版冒充正式单页。
- [ ] 内容、数字、箭头、标签、页码与策划一致。
- [ ] 无乱码、缺字、截断、遮挡和错误品牌图标。
- [ ] 真实素材的关键文字、数值、状态与特征保真，没有因整页编辑产生虚假操作或结果。
- [ ] 继承风格锚点，人物与素材正确。
- [ ] 需要修改的已修正；多页拼版从单页重做，没有裁切冒充。
- [ ] 已记录当前完成页与采用版本，便于继续时避免重复或漏页。

## I｜发布前

- [ ] 本次范围内的图片齐全、顺序正确、无重复；局部交付沿用全套编号，增删页已同步相关页码。
- [ ] 最新修改已同步到图片、标题和正文。
- [ ] 标题长度依 03 及有效配置，具体且与证据匹配。
- [ ] 正文只按主模板或有效字数配置执行，依 03 统一口径统计，没有叠加模板字数。
- [ ] 正文补充图片之外的信息，没有逐页复述。
- [ ] 口吻符合创作者设定，第一人称与实际素材一致。
- [ ] 关键来源、条件、适用日期在需要的位置出现。
- [ ] CTA 自然且可选，无虚构反馈或无意义口令。
- [ ] 实际未完成、待核实或待补素材已说明；受阻页未误标完成，其他已授权且不依赖它的部分已继续处理。
