# 小红书多主题图文｜发布文案规则 V3.1

完整套图中，图片承担核心内容，正文补充图片未展开的条件、经验、细节和延伸。本文件是标题与正文数值默认、字数口径、口吻和互动的唯一定义来源；只要文案的任务可直接执行，不等待图片。

## 一、按体裁分工

| 内容体裁 | 图片重点 | 正文补充 |
|---|---|---|
| 方法／教程／科普 | 框架、步骤、机制和示例 | 如何开始、常见卡点、适用条件 |
| 趋势／资讯 | 事实、证据、变化与判断 | 判断依据、影响、仍需观察的变量 |
| 清单／攻略／选型 | 筛选、比较、安排和优先级 | 取舍理由、更新条件、执行细节 |
| 体验／测评 | 测试条件、结果、优点与限制 | 使用背景、观察局限、适合谁 |
| 经历／复盘 | 事件、选择、行动与结果 | 当时的考虑、遗漏、可借鉴条件 |
| 共鸣／观点／话术 | 场景、表达、视角与回应 | 更完整的情境、边界、替代表达 |

正文不能只是图片逐页转写，也不能提出与图片证据相矛盾的新结论。

## 二、标题

- 默认 20 字以内，为本项目编辑默认，不作为平台限制的说明。
- 写清具体问题、收获、场景或判断，让读者知道是否与自己有关。
- 可以承接封面，但不机械照抄。
- 不夸大效果，不把个案写成普遍结果，不制造焦虑或性别对立。
- 趋势判断与证据强度匹配；不确定的内容保留不确定性。
- 没有使用者提供的真实依据，不写“亲测”“我坚持了”“我靠它获得”等体验承诺。

可按体裁使用的标题方向：

- 方法：完成什么任务，先做哪一步。
- 清单：在什么场景下，需要准备什么。
- 选型：什么需求适合什么选择。
- 故事：一次具体变化带来了什么认识。
- 观点：在什么处境下，提供什么新视角。
- 攻略：什么时间、预算或人群下的安排。

以上是方向，不要求套固定句式。

## 三、正文长度

先按 05 继承本次有效配置。只有未指定且无已确认的任务／账号字数设置时，使用以下项目编辑默认；不将其解释为平台上限或流量规则：

| 模板／体裁 | 正文默认 |
|---|---|
| T01、T02、T03、T04、T05、T07、T14、T15：知识、方法、判断与拆解 | 350～450 字 |
| T06、T08、T13：清单、体验、攻略 | 250～450 字 |
| T09：经历／故事复盘 | 350～600 字 |
| T10：共鸣／观点 | 150～300 字 |
| T11：沟通／话术 | 200～400 字 |
| T12：挑战／习惯养成 | 250～450 字 |

混合模板只按主模板取默认，不累加两个模板的字数，也不按某一页的版式判断体裁。信息已经完整时不为凑字数重复；无用户硬性字数要求时，可为完整表达作小幅调整并简要说明。明确字数要求则按有效配置执行。

字数口径：标题与正文主文案分别统计；以可见字符粗计，汉字、字母、数字、标点各计一个，不计空格与换行，表情按可见符号粗计。话题标签、完整来源链接与交付说明另列，不计入正文主文案。此口径用于内部一致性检查，不冒称平台计数方式。

## 四、推荐写法

### 知识与方法

补一个图中没展开的关键条件 → 给一个易执行动作 → 提醒一个具体误区 → 给进阶或持续使用建议。

### 趋势与判断

交代为什么关注 → 区分事实与推演 → 翻译成对读者的影响 → 提示后续观察点。

### 清单、攻略与选型

说明筛选依据 → 交代预算／时间／人群条件 → 补充替代方案或执行细节 → 指出信息更新条件。

### 测评与复盘

说明背景与条件 → 补充关键观察或选择过程 → 解释结果的局限 → 给适合相似处境的建议。

### 共鸣、观点与话术

从具体处境进入 → 给出有理由的新视角 → 补充边界或替代说法 → 以小行动或自然余味收束。

这些是写作参考，不要求每篇填满相同段落。段落短而连贯，避免排比堆砌和连续金句。

## 五、创作者口吻与真实经历

- 根据账号选择专业、亲和、轻松、克制或个人化口吻，单篇保持一致。
- 创作者身份与目标读者分别设置；不自动用“姐妹们”等性别称呼。
- 第一人称须与真实经历主体一致；引用他人测试不能写成“我用下来”，助手执行的测试应标注执行者；没有使用者经历依据时用通用说明或明确示例。
- 建议、个人偏好、事实与引用分清，不把个人感受包装成统计结论。
- 真实人物、经历和聊天内容只使用本次提供且适合公开的必要信息。
- 观点类允许情感表达，但不替读者定义人格、关系或心理状态。

## 六、来源与更新

有关键事实、数据、引文、作品或变化信息时，在正文或适当位置给出可识别的来源及日期。小图放简短来源，完整链接可放正文或交付说明，避免二维码或长链接挤占主要信息。

价格、营业、版本、预约等信息按适用日期表达。引用原话准确并保持必要长度；自己的归纳不用引号冒充原话。

涉及专业主题时，结论依专业来源、适用条件和已知边界表达；不使用无依据的确定性承诺。

## 七、互动

只有内容自然需要时加入一个互动邀请：

- 分享自己的实际使用差异。
- 在明确条件下讨论选择。
- 补充其他做法或资源。
- 提出希望继续展开的问题。

不强制每篇 CTA，不使用无意义口令，不捏造评论或用户反馈。

## 八、默认交付

完整套图按任务范围完成图片后，默认输出：

1. 一个符合本文件标题规则与有效配置的发布标题。
2. 一版适合主模板、符合相应字数默认的完整正文。
3. 内容需要时补充来源、适用日期或自然互动。

用户要求只要图片、只要文案、提前文案、多个版本或其他长度时，按 05 的有效范围执行，不额外等待或生成其他资产。未完成图片前的文案作为文案版本交付，不声称已与尚未完成的图片逐页核对；图片完成或改动后再同步最终文案。
