# 连续出图防跑偏｜独立单页生成规则 V3.1

本文件由原“独立单页生成补丁”升级，约束正式图片的页面单位、连续执行和失败处理。视觉与单页版式见 02。

## 一、批量的唯一解释

“批量出图”“继续剩余页面”“生成全部内页”“一次完成后面几张”等，均指在同一任务中按顺序连续生成多张独立单页。

批量改变要完成的页数，不改变每张图片的页面单位。

一页一图。页面标题、页码显示与画幅读取 05 的有效配置，不额外重设默认；不能把多个完整页面装进一张正式单页。

## 二、正式单页必须满足

- 只对应当前一页，一个核心观点。
- 使用本次有效画幅，页面本身可作为正式单页使用。
- 页面级主标题按有效配置安排，允许必要的小标题、标签和卡片标题；不能混入其他独立页面。
- 如配置显示页码，使用当前页对应的正式导航编号；编号与变更见下。
- 页面不依赖从其他合集里裁切才能成立。

正式页码指本套图的页面导航；步骤、对象编号、时间、数据、书页原页码和截图内原有进度不是另一张正式页码。页面级主标题指本页排版的一层标题，截图、书页与卡片内自带的标题不自动构成另一张完整页面。失败判断看是否出现多个独立正式页面，不只数数字、标题或区块。

### 页码变更与局部交付

- 修改或单独交付现有 P5 时沿用全套编号，例如 5 / 9，不重编号为 1 / 1。
- 新建一张独立作品且配置显示页码时，按独立任务编号为 1 / 1。
- 增删页或换序后先更新策划编号与总页数，再同步所有受影响正式页、发布文字和采用版本；不能让新旧分母混用。
- 已采用 P1 的旧页码仅作参考图内容，不得覆盖当前页的有效编号。页码是否显示和位置始终以有效配置为准。

## 三、允许的单页内部结构

在同一页、同一个核心观点下，页面标题按有效配置安排，允许：

- 多个清单卡片、分类标签和分组信息。
- 左右对照、前后对比、同条件物品比较。
- 一个情境的漫画分格、连续动作或短对话。
- 照片与细节图组合、手账素材拼贴。
- 多个图表面板共同支持一个明确结论，且手机可读。
- 表格、矩阵、工作纸和路线图。

这些是单页的信息分区，不是多个独立页面。不能只因出现网格、卡片或漫画分格就判为拼版。

## 四、禁止作为正式页面的形式

- 把 P2、P3、P4 等多个完整页面缩小并排在一张图中。
- 一张图出现属于不同正式页面的导航编号，或多个明显独立的海报版式。
- 用九宫格、多宫格、storyboard、contact sheet、海报墙或整套缩略图冒充独立单页。
- 先生成多页合集，再裁切、放大其中一格作为正式页面。
- 用户要求正式出图，却只交付整套预览图。

“禁止多宫格”针对不同完整页面的合集，不针对同一页内部服务一个观点的内容分区。

## 五、Style Anchor 与参考图

P1 按 05 完成确认或按免确认授权采用后作为风格参考，后续页继承主色、背景、字体层级、线条、边框、图标、图片处理、高亮、密度、留白与页码。

参考 P1 不等于将 P1 放在当前画布里，也不要求每页复制封面布局。
人物只在本页策划需要时出现，参考已选角色图；不生成跨页人物动作合集。

## 六、当前页的信息隔离

每次生成可参考：本次已采用的 P1、风格参数、适用角色参考、当前页文字、结构、素材及必要上下文。

画面只能表达当前页。其他页的完整标题、正文、页码和版面不能作为画面任务输入。

例如生成 P6 且配置显示页码时，本页正式编号为 6 / N；相邻页只用于理解逻辑，不在画面中展开。

## 七、连续生成流程

1. 读取本次有效策划、已采用的 P1、风格参数与授权范围；确认状态依 05，免确认任务不重复索取审批。
2. 确认下一张尚未完成的页码。
3. 提取该页实际文案、主版式、素材和人物安排。
4. 检查独立页面单位、有效画幅、主标题、核心观点与配置要求的正式编号。
5. 独立生成当前页。
6. 立即检查结构、文字、数字、素材、人物、风格和页码。
7. 能在现有条件下修正的问题先修正，通过后记录采用版本；缺素材或其他确实受阻的页面记录为待处理，不标完成。
8. 默认按页码继续。某页受阻时，可推进不依赖它且已经授权的其他页；P1 或共同依据未满足时，不越过依赖它的阶段。最终仍按页码交付，并明确未完成项。

用户已授权继续所有剩余页时，不每完成一页就重新询问。若被中断，依据已完成页与采用版本继续，避免重复或漏页。

## 八、生成后失败判定

满足以下任意一项，判定为正式单页生成失败：

- 出现属于不同正式页面的导航页码，或本页编号与有效策划不一致。
- 存在两个或以上完整页面版式。
- 多张独立海报被缩小后塞进一张画布。
- 需要从整套合集裁切才能获得当前页。
- 生成结果为整套预览，而任务要求正式单页。

单页内部卡片、漫画分格或对象编号本身不构成失败；仍需检查它们是否共同服务一个核心观点。

## 九、错误处理

- 文字、位置或细节错误：优先基于当前单页编辑，重新检查。真实素材的关键内容按 02 保真，不能因重绘整页改变证据。
- 多页拼版：放弃该合集结果，重新提取当前页，参考 P1 生成完整独立单页。
- 不从错误拼版中裁切、放大或继续沿用多页结构。
- 裁切单张照片、截图或局部细节以完成单页排版是允许的，不能把“禁止合集切图”误用于正常素材裁切。

若当前页未通过，不能记录为已完成，也不把待修图片混入最终版本。

## 十、预览与最终交付

只有用户明确要求整套预览、九宫格展示或作品展示图时，才额外制作多页同屏资产。预览不能替代正式独立页面。

最终检查：页数、顺序、分母、采用版本、标题与正文一致；所有正式页单独交付。

独立页面单位、内容真实性与本次有效配置均需通过检查；风格与连续生成效率不能成为绕过检查的理由。
