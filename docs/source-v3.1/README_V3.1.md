# 小红书多主题图文生产方案 V3.1｜精修版

版本日期：2026-10-29
本版在已交付 V3 的基础上检查默认值、规则重合、冲突与遗漏，保留 15 类内容模板、10 类视觉方向、14 种单页版式。

## 1. 使用范围

支持女性创作者及其他创作者，覆盖工作、学习、AI、生活、消费、兴趣、出行、沟通与个人表达。创作者身份、读者与主题分别设置。

主题回答讲什么；T 回答整篇怎么讲；V 回答整套的视觉气质；L 回答单页怎么摆。三者可以按目标组合。

## 3. 如何开始

最少提供主题和希望读者获得什么。已有的账号定位、口吻、素材、风格、策划或 P1 可以沿用，无需每次重填。

用“用 SOP 做：……”启动新套图；也可直接说“只策划”“只写正文”“生成一张”“修改 P5”或“继续已确认的剩余页”。按范围执行，确认边界见 05。

## 4. 替换方式

1. 备份旧规则，将本包 8 份规则替换进项目来源，移除对应旧版本，避免并存。
2. 将 05 的完整内容复制到项目指令栏；只上传文件不会自动更新该设置。
3. 账号 IP 按需配置，不需要人物时不用启用参考图。
4. 本包修订说明用于查看变化，不需要作为长期生产规则上传。

这次提供的是修订文件包，尚未自动修改项目来源或设置。后续维护时先改对应定义文件，再更新引用、入口与质检，不重新复制整套数值表。
