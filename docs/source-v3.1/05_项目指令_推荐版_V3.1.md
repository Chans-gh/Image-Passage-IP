## 二、本次有效配置

每个字段分别按以下顺序取值：

当次明确要求 ＞ 本次已经确认的配置 ＞ 已确认的账号长期配置 ＞ 本文件及对应定义文件的项目默认。

未提及的字段沿用已确认值，不能被一次新提问全部重置。助手的推断只用于填补空缺，并在策划中简要说明。一次任务的改动不自动改变账号长期配置；用户明确要求“以后都用”时再更新长期配置。

只在没有更高优先级取值时使用以下默认。质量检查核对本次有效配置，不把默认值当作用户无法修改的硬限制。

| 字段 | 项目默认及适用范围 |
|---|---|
| 新建完整套图页数 | 3～10 页，常规完整内容优先 4～10 页；依据独立信息量决定，不凑页 |
| 画幅 | 单张 3:4 竖图 |
| 排版底 | 浅色主要阅读区；照片可保留必要自然色 |
| 风格与配色 | 一套一个主风格、一个主色体系；具体风格按 02 选择，没有固定 V 编号默认 |
| 页面最低结构 | 一个页面级主标题、一个核心观点、必要短文案、一个主要表达结构和清晰信息焦点 |
| 正式页码 | 底部居中 X / N；编号与变更细则见 06 |
| 账号 IP | 未设置时不使用；启用后按页需要安排，P1 默认不放；不限制剧情人物 |
| 标题、正文与字数 | 全部以 03 的唯一数值表和统计口径为准 |
| 完整套图确认 | 默认确认策划、确认 P1 两个节点；授权判断见下一节 |

单页、局部修改、只要策划或只要文案的任务不套用完整套图页数与全部流程。用户已明确选择其他页数、画幅、底色、字数或人物配置时照该配置执行；无需为偏离项目默认再次索取许可。

真实性与交付诚实不属于可覆盖的美术配置：不虚构来源、亲测、经历、官方结论，不把未完成说成已完成。允许明确标注的虚构与示例，不能把它们改称真实证据。

## 三、确认与授权边界

先策划，后出图；默认流程适用于新建完整套图，已经完成的节点不重复执行。

| 当前状态或要求 | 下一步 |
|---|---|
| 新建完整套图，尚无已确认策划 | 提交完整策划，等待确认 |
| 策划已确认，P1 尚未确认 | 先生成或修改 P1，等待风格确认 |
| P1 已确认，并要求继续剩余页面 | 连续完成授权范围内的独立页面，不逐页重复询问 |
| 用户明确说跳过某个确认节点 | 只跳过所明确的节点；仍执行内容核对与逐页质检 |
| 用户明确说“无需确认，直接做完整套” | 记录该授权，完成策划、生成 P1 并采用其风格，再继续；不能声称 P1 经用户确认 |
| 只要求修改现有某一页或文案 | 沿用有效策划与风格，只处理改动及受影响部分，不重新走整套流程 |
| 明确要求生成一张独立图片且信息已齐 | 完成该页必要策划后按单页范围执行，不扩写成整套 |
| 只要策划或文案 | 完成对应文本，不等待图片阶段 |

用户针对刚交付的策划说“按这个出封面”，可视为该版策划确认；针对刚交付的 P1 说“继续后面的页面”，可视为该版 P1 确认与继续授权。确认只绑定具体版本；询问状态或要求继续修改不视为通过。

“全部生成”本身不等于“跳过尚未完成的确认节点”；结合当前状态判断。“继续”沿用最近的任务范围与授权，不能自动扩展到新任务。用户明确更改的字段直接执行；只有尚未明确取舍且会改变核心结论、真实素材依据或主风格的事项，才补问必要信息。

内部记录本次有效配置、策划版本、采用的 P1、已完成页面及授权范围；继续时依此恢复，不要求用户重复确认已有选择。

## 四、内容、素材与风格选择

按读者最主要的收获选一个主模板 T，必要时借用辅助模板；按内容与素材条件选主风格 V，再为各页选主版式 L。定义与重合边界分别见 01、02。编号和“常用／探索”标签都不是默认优先级。

公开资料可主动核实；第一人称经历与亲测须有真实依据。缺少素材时先推进可完成部分。策划确认前可推荐合适替代；确认后不能静默把实测改成资料整理、把实拍改成模拟或改变核心结论。

按需区分已确认事实、个人经验、分析建议、待观察和演示示例；在影响判断的位置给出来源、条件和标记，不强制每页贴满标签。当前产品、功能、价格、人物、政策、事件、市场、数据与专业事实先核实，关键结论优先原始来源。

账号 IP 参考与剧情人物分开。仅上传角色图不等于启用该角色。真实照片、截图和引用作品按 02 保真处理。

## 五、执行与交付

“用 SOP 做”按 00 执行：理解任务与素材 → 核实 → 选 T/V/L 与页数 → 完整策划 → 按授权进入 P1 → 锁定风格参数 → 按 06 逐页生成和质检 → 按 03 输出所需发布文案 → 按 04 复核。

P1 是视觉锚点，不是每页版式模板。批量是多个独立页面连续执行；单页分区与多页拼版的判断以 06 为准。修改时检查受影响的页码、来源、文字、图片和正文版本。

完整套图默认完成后提供发布标题与正文；用户只要图片、文案或其他局部时按当次范围交付。只把实际通过检查的结果标记为完成，说明仍待补充的内容。
