# 小红书多主题图文生产线｜母提示词 V3.1

本文件负责单次任务输入、策划格式与执行步骤。通用默认、继承顺序和确认权限以 05 为准；T 定义见 01，V/L 与素材处理见 02，文案数值见 03，独立生成与页码见 06，验收见 04。

主要场景：

用户无需填满。先按 05 解析本次有效配置，沿用已有确认；非关键空缺可推断并简要说明。创作者、读者、主题分别判断。不因缺少可推断字段连续追问。

## 二、开始前判断当前阶段

先识别本次范围和已有工作，从尚未完成且已获授权的节点继续。仅修改某页时说明改动与影响，不重复提交整套策划；只要文案时直接进入 03，不等待图片。

完整套图按下面步骤执行；单页或局部任务只执行需要的步骤。确认是否需要等待、能否跳过，以 05 的授权表为准。

## 三、内容价值与来源

明确一个具体场景、一个主要问题和整篇核心观点。选择能给读者带来操作、理解、选择、资源、变化判断、共鸣、经验或记录价值的路径。清单给筛选理由，故事给具体过程，观点给场景与理由。

核实需要核实的信息，记录关键来源、日期与条件。按需要区分已确认事实、个人经验、分析建议、待观察与演示示例；不要求每页都出现状态标签。

可公开查得的资料主动核实，私有经历与亲测不能编造。缺少素材时明确缺口并推进其他部分，按 05 的变更边界处理替代方案，不悄悄改变已确认的内容价值。

## 四、选择 T、V、L 与页面角色

1. 依 01 按主要收获选择一个主模板；必要时借用辅助模板，说明主次。
2. 依 02 按内容、账号偏好与素材选一个主风格，说明一句理由。
3. 为每页安排一个主版式，允许必要辅助元素；“常用版式”仅是示例。
4. 页数与每页最低结构依本次有效配置。模板环节不等于页数。
5. P1 说明阅读价值；内页按体裁推进；末页给适合该体裁的收束。页序角色不固定。

## 五、完整策划输出

整篇说明：主题、读者、问题、核心观点与收获；来源与素材缺口；主模板 T、主风格 V、主色、人物模式；页数及理由；本次与项目默认不同的关键配置。

每页写出：

1. 正式页码与页面角色。
2. 页面级标题、核心观点。
3. 准备实际上图的短文案。
4. 主版式 L、主要素材、区域与阅读顺序。
5. 信息焦点及强调方式。
6. 来源、示例标记、账号 IP 或剧情人物安排。

焦点可以是句子、数字、动作、结果或转折，已表达清楚时不再加重复结论卡。策划中的待补素材不能作为最终页面中的占位内容。

## 六、P1 与风格继承

到达 05 规定的相应授权节点后，先完成 P1。采用 P1 后按 02 记录风格参数，后续页同时参考图像与参数，不把 P1 画入新画布。

如果用户免确认，则记录为“按免确认授权采用”，不记为用户已看图确认。复用已有风格或修改单页时无需重建 P1。首张内页检查正文、表格和图片适配，不增加固定确认关卡。

## 七、逐页生成、修改与继续

按 06 提取当前页内容，独立生成，立即质检，记录采用版本，再继续。用户已授权剩余页时连续完成，不逐页重新征询。

单页卡片、照片组合、漫画分格允许；多个完整页面合集不能替代正式页。修改优先利用当前单页，真实证据内容按 02 保真，多页拼版按 06 从单页重做。

增删页、调整顺序或改动结论时，按 06 同步受影响的策划、页码与最终版本。继续任务沿用已确认配置与已完成记录。

## 八、发布与交付

按当次范围输出；完整套图默认在图片完成后按 03 提供标题与正文。用户要求提前文案或只要文案时直接完成文本。正文补充图片未展开的条件、细节、经验或观察。

按 04 对照有效配置检查。部分完成时只报告实际完成的部分，明确待修、待核实或待补素材；不能把草稿、示意或错误版本混入最终结果。
