# 角色资产（可选功能）

## 一、边界

- **默认不启用**。没有配置角色时，整套图不出现账号角色。
- 只上传了角色图**不等于启用**。需要在 `profile.md` 的 F 组或当次请求里明确启用。
- 角色只服务于叙事：辅助操作、观察、批注、对话。出现在哪些页、出现几次由内容决定，没有固定配额。
- **账号角色**和**剧情人物**分开：剧情人物是漫画或演示里的一次性人物，不自动视为账号角色。
- 不根据创作者的身份或性别自动选择、更换角色。
- 角色资产只建一次，之后跨项目反复使用。

## 二、人物模式

| 模式 | 说明 |
|---|---|
| 不使用账号角色 | 默认 |
| 使用用户上传的角色参考图 | 用户自备图片；整理出识别特征卡（第三节）后使用 |
| 先生成角色资产，再使用 | 用第四节的模板生成一套资产，用户确认后存档 |

## 三、角色资产包

位置：`image-passage-work/_assets/characters/<角色名>/`

| 文件 | 内容 | 用途 |
|---|---|---|
| `character.md` | 识别特征卡（模板 `templates/character.md`）：名字、定位、画风、发型发色、服装、主色、头身比、识别特征、**不可改变项**、可变项、出现规则、使用权 | 所有路线都读取；不可改变项写进每页提示词的第 6 层 |
| `sheet.png` | 三视图设定图：正面、侧面、背面全身 | native / api 的主参考图 |
| `expressions.png` | 表情组 | 按页面情绪选用 |
| `poses/*.png` | 常用动作单图，**透明背景** | svg 路线直接嵌入；native / api 也可作参考 |

svg 路线画不出一致的角色，只能嵌入现成的透明 PNG。所以动作单图要做成透明背景；接口不支持透明背景时，用纯白背景生成，再抠图（任何抠图工具均可，结果存为 PNG）。

### 用户上传角色图时

1. 复制到资产目录。
2. 能看图时，从图里整理特征卡，请用户确认「不可改变项」。不能看图时，请用户填写特征卡。
3. 确认用户拥有使用权，写进特征卡。
4. 缺少透明动作图而又走 svg 路线时，说明限制：角色只能以现有图片出现，或改为不出现。

## 四、生成角色资产的提示词模板

这三个模板用于**生成资产**，是一次性的准备工作，不受「一页一图」约束。表情组的网格是资产图的内部结构，不是多页拼版。

```text
【角色设定图｜Character Reference Sheet】

用途：为图文账号建立一个可反复使用的固定角色，本图只用作参考，不用于发布。

角色定位：{一句话，例如：陪读者整理工作方法的伙伴}
画风：{例如：扁平插画 / 彩铅手绘 / 日系简笔 / 3D 软萌}，与账号主风格 {V 编号} 协调
外观：
- 年龄感与体型：{例如：成年，三头身 Q 版 / 七头身写实}
- 发型与发色：{ }
- 服装：{上装、下装、鞋}，主色 {颜色名}，辅助色 {颜色名}
- 识别特征：{例如：圆框眼镜、胸前徽章、固定发夹}（2～3 个，全图保持一致）
构图：
- 同一张横版画布，纯白或浅灰纯色背景
- 同一角色的正面、侧面、背面全身三视图，并排，大小一致，脚底对齐
- 无文字、无水印、无场景、无其他人物
要求：三个视角的发型、服装、配色、比例和识别特征完全一致；线条干净，便于后续参考。
```

```text
【表情组｜Expression Sheet】

参考：角色设定图，保持外观完全一致。
内容：同一角色的头部或半身，{6} 种表情排成 2×3 网格：
{开心 / 认真思考 / 惊讶 / 无奈 / 鼓励 / 专注}
背景：纯白；无文字、无水印。
```

```text
【动作单图｜Pose】

参考：角色设定图，保持外观完全一致。
动作：{例如：一手指向右侧 / 双手举着空白牌子 / 低头看手机 / 拿笔记录 / 托腮思考 / 比 OK}
构图：单个角色全身，居中，四周留白；透明背景（不支持时用纯白背景，后期抠图）。
无文字、无道具上的字、无水印。
```

- api 路线：`call_image_api.py --prompt-file … --fit none --out _assets/characters/<名>/sheet.png`（资产图不裁切为 3:4）；表情组和动作图带上 `--ref sheet.png`。
- 生成后请用户确认设定图，再生成表情和动作。确认后把特征卡里的「不可改变项」写全。

## 五、在页面里使用

- 规格单「人物」字段：角色名、动作（选用哪张 pose）、位置、约占画面比例（≤1/3）。
- native / api：提示词第 6 层写角色名、粘贴不可改变项，第 8 层说明参考图「#3 角色设定图：保持外观完全一致」。
- svg：`<img src="../../../_assets/characters/<名>/poses/point.png">` 嵌入；不在 HTML 里重画角色。
- 质检：发型、服装、配色、比例、识别特征与特征卡一致；角色不遮挡信息、不抢焦点。

## 六、真实性与权利

- 用户上传的角色图需要用户自己拥有使用权。
- 不仿制知名 IP、现有动漫或品牌角色；不在未经同意的情况下生成真实人物的肖像。
- 角色是账号的形象，不等于「创作者本人亲测」。第一人称经历仍需真实依据。
