# 提示词写法（native / api 路线的 G、H 页）

提示词由页面规格单编译，写进 `pages/PNN/prompt.md` 的 ```text 代码块。`call_image_api.py --prompt-file` 只发送第一个 ```text 代码块。

## 一、8 层结构（顺序固定）

```text
【1 画布】竖版 3:4，1242×1656。一张完整、独立的单页。不要拼版，不要出现其他页面或缩略图。

【2 风格】（逐字粘贴 style-lock.md 描述版）

【3 版式】L05 步骤流程。顶部 18%：页面标题；中部 70%：三个竖向排列的步骤卡片，卡片之间用向下箭头连接；底部：页码。阅读顺序：标题 → 步骤 1 → 2 → 3。

【4 文字】只出现以下文字，逐字使用，不增、不改、不翻译：
  主标题：「三步救回黄叶绿萝」（最大、最粗）
  步骤 1：「剪掉黄叶」
  步骤 2：「换疏松土」
  步骤 3：「放散射光处」
  页码：底部居中「3 / 8」，小字

【5 素材】参考图 #2 是用户实拍，保持主体和构图不变，只加手账胶带边框。

【6 人物】不出现。

【7 禁止】水印、乱码、多余文字、其他页的内容、伪造的真实界面记录。

【8 参考图说明】#1 P1 封面：只参考风格，不复制构图和文字。#2 用户实拍。
```

| 层 | 写法要点 |
|---|---|
| 1 画布 | 每页都写，不省略。这一层从结构上防止多页拼版 |
| 2 风格 | **逐字**使用风格锁描述版，不每页改写。P1 时由你写出描述版的初稿 |
| 3 版式 | 写区域比例和位置（百分比）、阅读顺序；不写 L 编号以外的术语给模型猜 |
| 4 文字 | 逐条列出，每条标层级和相对大小；用「」包住原文。没有文字的区域写「留白」 |
| 5 素材 | 写清每张素材的处理方式：保持不变 / 只加边框 / 只作风格参考 |
| 6 人物 | 不出现，或：角色名、外观以特征卡为准（粘贴不可改变项）、动作、位置、约占画面比例 |
| 7 禁止 | 通用禁止项＋本页禁止项 |
| 8 参考图 | 按编号说明每张参考图的作用和「只参考什么」 |

## 二、中文上图文字

- G 页的上图文字尽量少：主标题 ≤14 字，其他文字合计 ≤30 字、≤4 条。超过时改用 H（`page-generation.md` 第二节）。
- 每条文字单独一行、用「」包住；不要把多条写成一句话。
- 不要求模型写长句、小字号正文、表格、数字密集的内容。
- 英文、数字和品牌名照原样写，注明「保持大小写」。
- 质检时逐字核对（能看图时看图；否则 `ocr_check.py --expect-file spec.md`）。

## 三、各风格的描述版起点

写 P1 时，从对应风格的起点出发，加上本套的颜色名、字体感和组件，写成 80～160 字的描述版。

| 风格 | 描述起点 |
|---|---|
| V01 | 浅色素描纸底，轻微纸纹；彩铅手绘线条和半透明色块；手绘圆角卡片、便签和箭头；标题为手写感粗字，正文为清晰的手写楷体；图标简笔 |
| V02 | 暖白编辑页底；细线分栏，研究简报感；关键数字放大；主结构图线条精细；少量红色分析批注；底部来源条 |
| V03 | 纯净浅色底，充足留白；清晰的现代黑体，层级分明；规则分区，少量主色色块；简洁线性图标；圆角卡片，细描边 |
| V04 | 大幅实拍照片为主；编辑式衬线大标题；短图注；网格对齐；少量栏目标签；杂志内页质感 |
| V05 | 手账纸张底；便签、票据、和纸胶带、轻微错落的拼贴；手写标注；暖色调；装饰克制 |
| V06 | 真实照片或截图为主；醒目的箭头、圆圈圈注和局部放大框；简短说明标签；干净的底色 |
| V07 | 扁平插画，简化几何形状，有限色板；人物和物件比例合理；无描边或细描边；浅色背景 |
| V08 | 统一画风的漫画分格，2～4 格；角色表情和动作清楚；对话气泡留白充足；格框线条一致 |
| V09 | 图鉴档案页：对象居中展示，统一编号和标签位置，档案卡片边框，观察维度一致 |
| V10 | 书页质感，米白纸张；衬线正文；页边手写批注；引文用引号和细分隔线；克制 |
| V11 | 纯色或浅色底；巨大、清晰的中文字为画面主体；1～2 处主色高亮；最多一个简笔涂鸦 |
| V12 | 仿备忘录 / 便签 / 待办界面：顶部状态栏样式、圆角卡片、勾选框；通用界面，不出现任何真实产品 Logo |

## 四、P1 封面

P1 没有风格参考，靠描述和用户的风格参考图：

- 第 2 层写描述版初稿；第 8 层说明风格参考图（profile 的 `_assets/style-refs/` 或本次的参考图）「只提取风格，不复制构图和内容」。
- 第 4 层按封面主文案：主标题 ≤14 字，副标题 ≤16 字；大字报 ≤20 字。
- 第 3 层按封面形态 C 描述构图（`visual-system.md` 第四节）。
- 不画页码。
- P1 采用后，把实际效果反写进描述版（「标题为圆润粗黑体，字占画面宽度约 80%」），之后逐字复用。

## 五、H 页的底图提示词

底图只画画面，不画文字：

```text
【1 画布】竖版 3:4，1242×1656。一张完整、独立的单页底图。

【2 风格】（描述版）

【3 版式】以下区域保持干净留白，不画任何文字、图形或纹理以外的元素，后期会在这里叠加文字：
  区域 A：顶部，从上边缘向下 8%～22%，左右各留 5%（标题）
  区域 B：中部，30%～85%，左右各留 8%（正文卡片）
  其余区域：可以画与主题相关的装饰：绿萝叶片、花盆、浇水壶，线条风格一致。

【4 文字】画面中不出现任何文字、字母、数字或类似文字的笔画。

【7 禁止】文字、水印、Logo、二维码、界面截图。

【8 参考图说明】#1 P1 封面：只参考风格。
```

- 留白区的百分比要和 `page.html` 中 `.zone` 的坐标一致（1242×1656 下：8% ≈ 132 px，5% ≈ 62 px）。
- 底图里出现了类似文字的笔画时，重新生成或用 `.zone.plate` 加底色块遮住。

## 六、修改提示词

工具支持局部编辑（传入原图）时：

```text
基于参考图 #1（本页当前版本）只做以下修改，其他所有内容保持完全不变：
- 把主标题「三步救回黄叶绿罗」改为「三步救回黄叶绿萝」
不改变构图、配色、其他文字和页码。
```

不支持局部编辑时，修改 `prompt.md` 后整页重新生成；文字反复出错时改用 H。

## 七、参考图

- api：`call_image_api.py --ref 文件 --ref 文件`；顺序和第 8 层的编号一致。`IMAGE_API_REFERENCE_MODE=none` 时不传参考图，只靠描述版。
- native：按环境的方式附上参考图（例如附加图片文件）；不支持时只靠描述版，并在策划里说明一致性会变弱。
- 参考图只传本页需要的：P1、内页锚点、本页角色图、本页素材。不传其他内页。

## 八、尺寸与裁切

- 很多接口只支持 2:3（1024×1536），脚本会居中裁切为 3:4，上下各裁掉约 5.5%。
- 所以提示词里的重要内容不要贴近上下边缘：标题区从 8% 以下开始，页码区在 92% 以上，必要时在第 3 层写「上下各留 8% 安全区」。
- 原图保存为 `vN.raw.png`，裁切结果为 `vN.png`。需要不同的适配方式时：`image_tools.py fit 原图 输出 --mode contain --bg "#F5EFE3"`（`--bg` 用 HEX，可用 `palette.py resolve` 查）。

## 九、语言

默认全中文。中英双语或英文提示词的效果需要在各环境实测（`render-routing.md` 第五节）。上图文字永远保持中文原文，不翻译。
