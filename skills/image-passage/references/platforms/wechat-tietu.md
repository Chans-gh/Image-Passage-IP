# 平台预设：微信贴图号

平台上限是外部硬约束，不能被配置覆盖。以下上限由作者于 2026-10-30 确认，两个平台统一使用（`assets/platforms.json` 中 `verified: true`）。

| 项 | 值 | 说明 |
|---|---|---|
| 画幅 | 3:4，输出 1242×1656 | |
| 图片数上限 | 15 张 | 一套图最多 15 页（F5 长套为 11～15 张） |
| 标题上限 | 20 字 | 与项目默认一致 |
| 正文上限 | 800 字 | 按本项目字数口径统计，不含标签（`copywriting.md` 第五节） |
| 标签上限 | 8 个 | 项目默认 3～6 个，最多 8 个 |
| 首条评论 | 未设上限 | 项目默认 ≤150 字（`copywriting.md` 第十四节） |

## 发布习惯（编辑建议，不是平台规则）

- 封面在信息流和朋友圈转发中以缩略图出现，主标题在约 1/3 尺寸下要能看清。
- 标签写法按 App 实际支持的方式；不支持时省略。
- 首条评论在发布后由账号自己发出，平台支持时置顶。
- 商业合作按平台要求标注合作关系。

## 合规提示

- 广告与推荐内容避免绝对化用语、功效承诺、收益承诺。
- 不写换取点赞、收藏、关注、评论的口令；不做站外导流。
- 具体条款以平台最新的社区规范为准。

## 修改上限

平台规则变化或作者调整时，同时更新：

1. `assets/platforms.json` 中对应字段和 `verified_on`；
2. 本文件的表格；
3. `CHANGELOG.md`。
