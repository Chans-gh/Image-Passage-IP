# 执行与质检清单

按阶段与本次范围检查，不适用的项标「不适用」，不算失败。本清单不新增规则、默认值或确认节点；核对的是本次**有效配置**（`workflow.md` 第二节），不把项目默认当成硬限制。

质检方式取决于 `state.json` 的 `render.qa_mode`：

| qa_mode | 能检查的 | 检查不了的 |
|---|---|---|
| visual | 全部 | — |
| script+ocr | S / H 页的排版（`render_page.py`）；G 页的文字（`ocr_check.py`） | G 页的画面、人物、风格 |
| script-only | S / H 页的排版 | G 页的全部 |

检查不了的项如实写「未经视觉检查」，请用户抽查，不标为通过（`workspace.py adopt --qa pass-script-only` 或 `unchecked`）。

## A｜选题与读者

- [ ] 创作者身份、目标读者、主题 D 分别明确。
- [ ] 具体场景、主要问题、整篇核心观点明确；R、I 已选。
- [ ] 内容能提供方法、判断、筛选、观察、情境理解、可借鉴经验，或 R 中的情感 / 社交价值。
- [ ] 没有按性别预设主题、审美、能力或称呼。
- [ ] 工具、预算、时间和知识前提符合目标读者。
- [ ] 横切属性已判断：敏感等级、时效、地域、商业属性。

## B｜事实与真实素材

- [ ] 需要核实的当前信息已查证，关键来源和日期可追溯。
- [ ] 产品名、人物身份、时间、功能状态、价格、数字和单位准确。
- [ ] 重大事实优先原始来源，不用单一二手截图支撑重大结论。
- [ ] 已确认事实、个人经验、分析建议、待观察、演示示例按需区分。
- [ ] 第一人称经历、亲测、前后结果有用户提供的依据。
- [ ] 演示 / 虚构示例明确标注，没有冒充真实记录。
- [ ] ⚠️ / ⛔ 领域：专业结论有专业来源，条件与边界清楚，有提示语。
- [ ] 引用、作品、截图和真实人物信息有必要来源。
- [ ] **隐私**：截图中的手机号、姓名、订单号、地址、他人头像和昵称已遮挡；他人可识别面孔已获同意或模糊；未露出儿童正脸、学校、住址。

## D｜页面文案

- [ ] 每页标题、主要表达结构与短文案符合有效配置；页面与素材内部的标题层级清楚。
- [ ] 信息焦点清楚；没有为了凑强调句重复标题。
- [ ] 每页文字量不超过所用版式的上限（`visual-system.md` 第三节）；封面主文案符合第四节。
