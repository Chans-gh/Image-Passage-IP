# 视觉规范：风格、版式、封面、风格参数

本文件定义视觉风格 V、单页版式 L、封面形态 C、表达元素 E、风格参数与风格锁、配色与字体、素材保真。内容模板见 `content-templates.md`；怎么出图见 `page-generation.md` 和 `render-routing.md`。

## 一、基础规则

- 画幅读取有效配置（两个平台默认都是 3:4，1242×1656）。手机阅读优先。
- 一套图一个主风格 V、一个主色体系。中性色和功能色作为辅助，不逐页换配色。
- 照片、截图和作品保留必要的自然色，不为统一主色扭曲证据、物品颜色或界面信息。
- 统一字体层级、线条、边框、图标语言、图片处理和页码；布局可以逐页变化。
- 装饰服务于内容，给重要文字和画面留出空间。
- 每页一个清晰焦点。高亮 1～3 处，只强调关键词、数字或短结论，不整段涂色。
- 「浅色」指排版底和主要阅读区；照片局部的深色不算换风格。
- 手写风要保证中文清晰；正文不为氛围牺牲辨识度。
- 不根据创作者性别自动选择颜色、风格或角色。

### 风格重合与素材组合

主风格决定整套的字排、线条、配色和图片处理。照片、截图、引文、局部对话和图表可以进入其他主风格，不构成第二主风格（例如 V04 里可以有实拍批注）。但不能逐页切换完全不同的视觉语言。

| 容易重合 | 区分依据 |
|---|---|
| V01 与 V05 | 学习推导与流程笔记选 V01；记录、素材拼贴与日记感选 V05 |
| V02 与 V04 | 证据、数字与判断层级为主选 V02；图片与生活观察的编辑叙事为主选 V04 |
| V03 与 V09 | 通用信息层级为主选 V03；对象及统一观察字段为主选 V09 |
| V04 与 V06 | 大图编辑叙事为主选 V04；保真的操作、细节和结果批注为主选 V06 |
| V07 与 V08 | 图形解释概念为主选 V07；人物行动与对话推进为主选 V08 |
| V11 与 V03 | 字就是画面、几乎没有结构选 V11；靠分区和层级组织信息选 V03 |
| V11 与 V01 | 只有大字和极少涂鸦选 V11；有推导、流程和大量手绘图示选 V01 |
| V12 与 V05 | 仿数字界面选 V12；仿纸张和实物拼贴选 V05 |

## 三、单页版式 L（36 种）

版式只定义骨架；骨架里放什么见第六节表达元素 E。文字量上限是 1242×1656 画布、手机阅读下的建议默认值，可被有效配置覆盖。一个主版式可以容纳必要的辅助元素；表格、多个卡片或漫画分格只要仍是一个完整页面，就不属于多页拼版。

「CSS 类」是 `base.css` 中对应的布局类，S / H 页可以直接使用（`html-recipes.md`）。

## 四、封面形态 C 与封面主文案

封面形态引用一个版式，再追加封面专用规则。封面形态可以和内页不同，但色彩、字体、组件必须与内页一致。钩子 H 见 `content-templates.md` 第五节。

| 编号 | 封面形态 | 引用版式 | 适合 | 封面专用规则 |
|---|---|---|---|---|
| C01 | 极简大字报 | L15 | T10、T11、T19、F1 | 纯色或浅底；只有大字；高亮 1～2 处；字占画面 40～60% |
| C02 | 手绘大字报 | L15 | T10、T12、T16、F1 | 手写感大字＋1～2 个简笔涂鸦＋纸感背景；手写字清晰 |
| C03 | 大字＋核心视觉 | L01 | 通用 | 一个主视觉，大字不压主体 |
| C04 | 大字＋实拍 | L19 / L01 | T16、T08、T13 | 照片用户提供；文字区避开主体，必要时加底色块 |
| C05 | 角色＋大字 | L31 / L01 | 启用账号角色时 | 角色指向或举着大字；角色不超过画面 1/3 |
| C06 | 对比分屏 | L03 / L04 | T04、T07、T19 | 左右或上下对称，标签清楚 |
| C07 | 清单预览 | L09 / L29 | T06、T01 | 露出 3～5 个要点，其余留在内页 |
| C08 | 截图＋标注 | L10 | T01、T08 | 截图保真；标注一个重点 |
| C09 | 多图拼贴 | L20 | T16、T06 | 照片 ≤4 张，留出标题区 |
| C10 | 杂志封面 | L19 | V04 | 栏目标签＋大图＋编辑式标题 |
| C11 | 便签／备忘录／书页 | L16 / L17 | V05、V10、V12 | 仿纸张或系统界面，不伪造真实记录 |
| C12 | 问题卡／选择题 | L33 / L32 | T18、T19、T05 | 问题一行；选项清楚 |
| C13 | 单图全内容 | 任意 L | F1 | 封面即内容页，按所用版式的文字量上限 |

## 五、风格参数与风格锁

### 双锚点

- **P1 封面锚点**：确认节点。
- **内页锚点**：首张内页完成后，把正文、卡片、表格、图片处理的样式补进风格锁。**不新增确认节点**，只记录。
- 参考 P1 不等于把 P1 放进当前画布，也不要求每页复制封面布局。

### 风格锁的两个版本

- **描述版**：80～160 字的固定文字。native / api 路线**逐字**放进每一页提示词，不允许每页改写。
- **精确版**：HEX、字体名、字号、边距、线宽。用 `scripts/palette.py tokens` 写成 `render/tokens.css`，S 页和 H 页的文字层直接使用。

两者来自同一组参数，所以 G、H、S 三种页面看起来是一套。中途换渲染模式按「改变主风格」处理，重新确认 P1。

## 七、配色与字体

### 颜色：只写颜色名

- 策划、profile 和风格锁的描述版**只写颜色名**，例如「鼠尾草绿＋暖米白＋炭灰」。
- 主色体系按主题、账号和风格选择，不按创作者性别选。鼠尾草绿、灰蓝、暖棕、酒红、低饱和紫等只是示例。
- 功能色（对 / 错、好 / 差）只用于状态，并且同时用文字或符号，不只靠颜色识别。
- **native**：把颜色名写进提示词，并附 P1 参考图。
- **svg / H / api**：P1 渲染时由颜色名推导 HEX，写进 `style-lock.md` 精确版和 `render/tokens.css`。之后每页用同一组 HEX，不逐页重新推导。

```bash
python3 scripts/palette.py resolve 鼠尾草绿 暖米白 炭灰     # 查 HEX；表里没有的会提示
python3 scripts/palette.py list                            # 全部颜色名（assets/colors.json）
python3 scripts/palette.py tokens --out <项目>/render/tokens.css \
  --bg 暖米白 --text 炭灰 --primary 鼠尾草绿 --accent 雾蓝 --highlight 奶油黄 \
  --font-title noto-sans-sc --font-body noto-sans-sc --font-hand lxgw-wenkai
```

表里没有的颜色名，由模型推导一个 HEX，写进风格锁，同一套图内不再改。

### 字体：只用开源可商用字体

`assets/fonts.json` 列出可用字体，全部是 SIL OFL 协议。字体由 `scripts/fetch_fonts.py` 按需下载到 `~/.cache/image-passage/fonts`，不放进仓库。

| id | 字体 | 用途 |
|---|---|---|
| noto-sans-sc | 思源黑体 | 标题、正文（默认） |
| lxgw-wenkai | 霞鹜文楷 | 手写感批注、文艺正文（默认） |
| noto-serif-sc | 思源宋体 | 书页、杂志、引文 |
| zcool-kuaile | 站酷快乐体 | 活泼大字 |
| zcool-qingke-huangyou | 站酷庆科黄油体 | 圆润大字 |
| zcool-xiaowei | 站酷小薇 LOGO 体 | 文艺标题 |
| long-cang | 龙藏体 | 手写大字 |
| ma-shan-zheng | 马善政楷书 | 毛笔手写 |

- 标题、正文、注释建立少而明确的字号层级（≤4 级）。
- 正文用清晰的黑体或宋体；手写体、装饰字主要用于标题和少量批注。
- native 路线无法指定字体文件，只写字体感（「圆润粗黑体」「手写楷体」）。一套里混用 G 和 H 页时，G 页的字体描述要贴近 H 页实际使用的字体。

## 八、素材保真

真实照片、界面、测评结果和引用作品需要可核实的素材支持。生成插画可以表达概念或场景，但不能冒充真实操作截图、使用记录或原作品。

**允许**：为排版裁切、缩放、加圆角和边框、加批注；遮去无关个人信息（`image_tools.py mask`）。

**不允许**：改变关键文字、数值、按钮状态、物品特征或前后效果。

- 生成式重绘不是保真。需要保真的截图和照片，用 S 或 H 构成方式**原样嵌入**，不交给生图模型重画（`page-generation.md` 第二节）。
- 如果 G 页出现了证据内容变化，恢复原素材，改用 H / S 重新排版并核查。
- 替换注释层不能变成重写事实。
- 他人的作品、截图只作为参考或在有权使用时嵌入，并标注来源。

## 九、人物与角色

- 人物模式、角色资产包和提示词模板见 `characters.md`。
- 默认不使用账号角色；只上传角色图不等于启用。
- 账号角色出现时继承发型、服装、比例和识别特征，只辅助操作、观察或批注；出现次数由叙事决定，没有固定配额。
- 剧情人物用于漫画和演示；同一故事里保持身份和外观连续，不自动视为账号角色。
- svg 路线画不出一致的角色，只能嵌入透明背景的角色 PNG。
